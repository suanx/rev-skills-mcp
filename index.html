接入 MCP

端点：/mcp（POST，application/json）

{
  "mcpServers": {
    "rev-skills-android": {
      "url": "https://<your-edgeone-domain>/mcp"
    }
  }
}

CodeBuddy / Claude / Cursor / Cherry Studio 等支持远程 MCP 的客户端均可接入；将 URL 替换为实际部署域名。

工具（Tools）

  • list_skills

    列出全部 skills：名称、定位、触发词、references 索引。任务开始前先调用。

  • read_skill

    读取 skill 全文（skill + 可选 reference，默认 SKILL.md，可指定 references/ 子文档）。

  • search_skills

    跨 skills 全文检索（关键词 AND 匹配），返回相关片段与文件定位。
